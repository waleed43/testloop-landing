# TestLoop landing page

Marketing site for **TestLoop**, a working name for a Google Play closed-testing tester marketplace.

Live: <https://waleed43.github.io/testloop-landing/>

This is a static site (HTML, CSS, and a little JavaScript). There is no build step and no backend. The waitlist form is a placeholder and does not store or send data.

Product screenshots in `assets/` are from the TestLoop prototype and use demo data.

## Run locally

Open `index.html` in a browser, or:

```bash
python3 -m http.server 8080
# then visit http://localhost:8080
```

## What this page covers

- Play’s closed-test rule (12+ testers opted in for 14 consecutive days, per app, for personal accounts created after 13 November 2023)
- How it works for developers and testers
- SDK (`TestLoop.init`, Android + Flutter, heartbeats, offline queue, INTERNET only)
- Pricing: Free Exchange, Basic ($15), Pro QA ($59), Launch Ready ($149)
- Tester rewards, levels, streaks, referrals, and the professional track
- Policy-minded messaging (private feedback, never Play ratings or reviews)
- FAQ and a placeholder waitlist

Not affiliated with Google.
